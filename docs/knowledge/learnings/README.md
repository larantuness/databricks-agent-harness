# Learnings

One file per topic, for example `free-edition.md`, `cli.md`, `pipelines.md`.

Each learning has a status and a date:

```
- [verified] Serverless is the only compute I could select. Last checked: 2026-11-27
- [from-docs] ... Last checked: ...
- [unverified] ... Last checked: ...
```

`verified` means you ran it yourself. Re-check anything older than 60 days (`/memory-review`).
