# Labs

Each lab is individual: your VS Code, your Databricks Free Edition, your GitHub repository. Do them in order. About 45 minutes each; 03 and 04 are the core.

| Lab | You will | Output |
|---|---|---|
| 00 setup | Fork or use the template, clone it, install tools | A working local checkout |
| 01 connect | Log in to Databricks with OAuth | A working profile |
| 02 first run | Ask the agent to read the repo and do one safe task | First agent session |
| 03 build a story | Issue, branch, test, function, pull request | A merged story |
| 04 break and improve | Cause an error, log it, fix the harness | A commit to a skill |
| 05 write a skill | Turn something you repeated into a skill | A new skill |
| 06 share memory | Send a lesson to a shared knowledge repository | A pull request to it |

Mark each result `verified` only if you saw it work. Put surprises in `docs/knowledge/learnings/`.
