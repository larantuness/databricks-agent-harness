# Lab 00: initialize the project

1. Fork this repository to your GitHub account, clone your fork and open it in VS Code.
2. Open your agent chat and ask: "Inicialize o projeto seguindo o INIT.md" (or run `/setup` in Claude Code or Copilot).
3. Read the plan before you say yes. Run the logins yourself.

Done when: the agent's report shows every step of `INIT.md` as done, your fork has the backlog issues and the board, and tests and lint pass. If something is blocked on your machine, record it with `/log-error` and tell the instructor.
